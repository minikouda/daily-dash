Privacy policy

Daily Dash · last updated November 9, 2026

Daily Dash is a personal tool used only by its developer, on the developer's own computer, with the developer's own Google accounts.

What it accesses

Daily Dash requests read-only access to Gmail (gmail.readonly). It reads messages to find deadlines, to-dos, package shipments and important updates.

How data is used and stored

Email content and the results derived from it are stored only on the developer's computer. To extract information, message text is sent to Claude (Anthropic) for processing. Data is not used for advertising, is not sold, and is not shared with anyone else.

What it never does

Daily Dash never sends, deletes or modifies email. Reply drafts are only shown to the user, who copies them into Gmail and sends them personally.

Google API Services

Daily Dash's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local data folder removes everything Daily Dash stored.
